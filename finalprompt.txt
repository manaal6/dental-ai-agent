1. Test every part of the workflow from start to finish.

5. Continue testing until the entire pipeline is reliable.

* Law firms
* HVAC companies
* Plumbing companies
* Roofing companies

* Property management companies

## Contact Quality

Only return leads with strong contact information whenever possible.

Prefer:

* Owner
* Founder
* CEO

* Office Manager

The system must never return the same business more than once.

Implement duplicate detection using combinations of:

* business name
* phone number
* website
* email
* Google Maps ID (if available)
* domain

If a duplicate is detected, skip it automatically.
