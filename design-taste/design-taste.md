# Project Design Taste: Clinical Precision

Adopted on: 2026-11-06
Direction: Direction 1 — Clinical Precision (High-Trust Medical SaaS)

## Chosen System Specifications

- **Palette**:
  - Light Background: `#F8FAFC` (Slate Tint Surgical White)
  - Surface: `#FFFFFF`
  - Elevated / Interactive: `#F1F5F9`
  - Primary Accent: `#0F766E` (Deep Medical Teal / Sage)
  - Secondary Accent: `#0284C7` (Clinical Cyan)
  - Text Primary: `#0F172A` (Deep Slate Ink)
  - Text Secondary: `#475569`
  - Text Muted: `#94A3B8`
  - Subtle Hairline Borders: `#E2E8F0`
  - Live Status: `#059669` (Subtle Emerald)
  - Urgent / Attention: `#D97706` (Medical Amber)

- **Dark Mode Counterpart**:
  - Dark Background: `#0B111A`
  - Surface: `#111827`
  - Elevated: `#1E293B`
  - Text Primary: `#F8FAFC`
  - Text Secondary: `#94A3B8`
  - Border: `rgba(255, 255, 255, 0.08)`

- **Typography**:
  - Display / Headlines: `Plus Jakarta Sans`, sans-serif (Crisp geometric medical clarity)
  - UI & Data: `Geist Mono`, monospace (Tabular figures, timestamps, phone numbers, audio latencies)

- **Shape & Radii**:
  - Micro-radii: `6px` (`--radius-sm`), `8px` (`--radius`), `12px` (`--radius-lg`)
  - Crisp hairline 1px borders, zero excessive card stack nesting

- **Anti-Slop Guardrails**:
  - No purple-to-blue generic gradient heroes
  - No default system fonts or emoji icons
  - Real telephony soundwave audio visualizations & authentic dental appointment statuses
  - High WCAG AA contrast on all actions and status labels
